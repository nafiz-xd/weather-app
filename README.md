# Weather App 🌦️

Live weather for any city in the world — current conditions plus a **7-day forecast**.

## 🔗 Live Demo
👉 https://nafiz-xd.github.io/weather-app/

## ✨ Features
- Search any city (Dhaka loads by default)
- Current temperature, feels-like, humidity and wind
- 7-day forecast with daily highs & lows
- Powered by the free **Open-Meteo API** — no API key, no sign-up

## 🛠️ Tech
HTML • CSS • JavaScript • Fetch API • Open-Meteo — single page, hosted on GitHub Pages.
